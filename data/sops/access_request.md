# SOP: Access Request
## Purpose
Grant a user access to internal applications or shared drives.
## When to Use
User submits a ticket requesting access to a new tool, folder, or role change.
## Steps
1. Verify the user's manager has approved the access request in the ticket comments.
2. Check the user's role to ensure they meet the least-privilege requirements for the requested access.
3. Log in to the "DemoPortal" Admin Console and navigate to the User Management section.
4. Search for the user by their employee ID.
5. Assign the requested application group or shared drive permission based on the approved role.
6. Save the changes and verify the access is active.
7. Reply to the user confirming access and update the ticket status to "Resolved".
## Escalation
If the requested access is not available in the Admin Console, assign the ticket to the L2 team "IAM-Support" (fake group).
P1 cases (e.g., blocked from a critical deadline): call on-call lead at ext. 5678 (fake).
## Notes
- Always apply the principle of least privilege; do not grant admin access unless explicitly approved by IT Security.
- Revoke old permissions if this is a role change.
