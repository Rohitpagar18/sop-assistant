# SOP: Password Reset
## Purpose
Reset a user's password for the internal app "DemoPortal".
## When to Use
User reports "Account locked" or "Forgot password" via ticket.
## Steps
1. Verify the user's identity using employee ID and manager name in the ticket.
2. Log in to the DemoPortal Admin Console.
3. Search the user by employee ID.
4. Click "Unlock Account" if locked, then "Reset Password".
5. Send the temporary password to the user's registered email only.
6. Ask the user to change the password at first login.
7. Update the ticket with steps done and resolve it.
## Escalation
If the reset fails twice, assign to L2 team "DemoPortal-Support" (fake group).
P1 cases: call on-call lead at ext. 1234 (fake).
## Notes
- Never share passwords on Teams or call.
- Account locks after 5 wrong attempts.
